# Decisions

One file per decision, captured at the moment it is made.

Use `/decision-log` rather than writing these by hand — it captures the reasoning,
alternatives, assumptions, confidence, and the tripwires that would make you revisit.

This is the highest-leverage folder here. It separates whether a decision was *good* from
whether the outcome was *lucky*, and it means you never relitigate a settled call because
nobody remembers why.
