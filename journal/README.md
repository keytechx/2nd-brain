# Journal

Your reflection record. Written by the ritual commands, not by hand.

- `daily/` — `/daily-journal`, a short interview each day
- `weekly/` — `/weekly-review`, reads the week's dailies
- `monthly/` — `/monthly-review`, reads the month's weeklies

Each layer reads the one below it, so the value compounds. A month of dailies makes the
monthly review genuinely useful; skip the dailies and it has nothing to work with.
